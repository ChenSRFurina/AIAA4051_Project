# Question Answering Skill

## Global Guidance

### General Principles

1. **Strict Adherence to Context**: Answers must be derived strictly from the provided context. Do not use external knowledge to fill gaps or infer answers not explicitly stated in the text.
2. **Precision in Extraction**: Extract only the specific entity or fact requested. If the context mentions a broader category (e.g., "United Kingdom") but the question asks for a specific instance (e.g., "London"), do not generalize unless the text explicitly links them as the answer.
3. **Complete Workflow Execution**: Every step in a selected Task Graph's **Workflow** must be executed in order. Skipping steps or assuming outcomes is prohibited.
4. **Exact Node Matching**: When executing a workflow, use the exact node names defined in **Node Lists**. Do not paraphrase node names.

### Graph-structured Skill Execution Guide

1. **Task Selection**: Before solving, scan the **Task Graphs** section to identify the task type whose **Use when** condition best matches the current question.
2. **Workflow Execution**: Once the relevant task type is identified, execute its **Workflow** sequentially from top to bottom.
3. **Node Execution**: For each numbered item in the workflow (e.g., `1. Node A`), locate the corresponding node in the **Node Lists** section and execute its instructions.
4. **Verification**: After completing the workflow, verify the final answer against the context to ensure it directly answers the question without hallucination or over-generalization.

## Node Lists

### Identify Contextual Entities
Scan the provided context to identify all explicit mentions of entities (people, places, objects, organizations) and facts relevant to the question.

### Locate Specific Attribute
Search the context specifically for the attribute, property, or relationship requested in the question (e.g., type, developer, location, count) linked to the identified entities.

### Extract Exact Answer
Extract the precise text segment that directly answers the question, ensuring no generalization or omission of required details (e.g., full names, specific types).

### Verify Against Context
Review the extracted answer to confirm it is explicitly supported by the text and matches the question's constraints without hallucination.

### General Principles

1.  **Strict Grounding**: Answers must be derived exclusively from the provided documents. Do not use external knowledge, assumptions, or general facts not explicitly stated in the text.
2.  **Granularity Precision**: Ensure the retrieved information matches the specific granularity requested (e.g., exact entity names, specific dates, precise relationships). Do not answer with a broader category if a specific link is required.
3.  **Chain Verification**: If an answer depends on a chain of reasoning (e.g., Entity A is related to Entity B, which is related to Entity C), verify that every link in the chain is explicitly stated in the text before concluding.
4.  **Contextual Consistency**: Review surrounding context to ensure no contradictory information exists and that the answer does not rely on unverified assumptions.
5.  **Exact Extraction**: Extract values as direct excerpts or minimal, faithful paraphrases of the source text. Avoid adding interpretation or modifying the original meaning.

Do not infer a missing hop or relation solely because the final answer string differs from the source text.
